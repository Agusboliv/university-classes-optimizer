# web

Web estática (Next.js 16, `output: "export"`) para explorar el escenario
calculado de antemano. Ver `../CLAUDE.md` (secciones Diseño y Comandos) y
`../docs/plan-fase2.md`.

```bash
npm install
npm run dev      # copia ../data a public/ y levanta el servidor de desarrollo
npm run build    # genera out/ (servir con: npx serve out)
npm run lint
```
